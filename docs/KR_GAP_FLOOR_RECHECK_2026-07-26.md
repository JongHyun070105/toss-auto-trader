# 국내 갭 하한 재백테스트

작성일: 2026-07-26

대상 전략: `robust_gap5_stop0225_take12`

연구 코드: `scripts/kr_gap_floor_sensitivity.py`

## 최종 결론

실전 raw 갭 범위는 `-31% 이상, -5% 이하`로 유지한다.

이번에 추가된 `-31%` 하한은 과거 전략보다 갭 범위를 넓힌 것이 아니다. 과거
규칙은 `-5% 이하`만 검사해 하단 제한이 없었고, `-31%` 하한은 그중 기준가가
직접 비교되지 않을 가능성이 큰 극단값만 제거한다.

`-25%` 하한은 전체 이력에서 소폭 좋아 보였지만 NXT 이후 일반 후보 선택을 한
건도 바꾸지 않았다. 이미 여러 연구에서 사용한 2024년 이후 자료에서도 새 증거가
없으므로 실전 승격 근거가 아니다. `-15%`, `-12%`, `-10%`, `-8%`로 더 좁히면
거래 수와 누적손익이 감소했고 일부 경우 MDD도 악화됐다.

## 고정 검증 설계

- 데이터: 기본 DB, 상장폐지 60일 전 제외 보강 DB, 상장폐지 전체 보강 DB
- 기간: 2011-01-01~2026-07-23
- 고정 하한: 없음(과거 규칙), `-31%`, `-30%`, `-25%`, `-20%`, `-15%`,
  `-12%`, `-10%`, `-8%`
- 비용: harsh 왕복 `1.35%`, extreme 왕복 `2.45%`
- 구간: 2011~2018, 2019~2023, 2024~NXT 전, NXT 이후, 2026, 전체
- 강건성: 상위 수익 거래 25% 제거
- 자금: 거래마다 고정 10,000원, 정수 주식 수량
- 후보 선택과 청산: 기존 최저시가 1순위, `-2.25%` 손절, `+12%` 익절,
  15:20 잔여 청산을 그대로 사용

하한 목록은 결과를 보기 전에 코드 상수로 고정했다. 이 실행은 새 하한을
최적화하거나 자동 승격하지 않는다.

## 갭 폭 해석

과거 하단 제한 없는 규칙이 선택한 기본 DB 399건의 중앙값은 `-7.15%`, 하위
5% 지점은 `-16.40%`였다. `-10% 이하` 104건, `-15% 이하` 29건,
`-20% 이하` 13건, `-30% 이하` 2건이었다. 최근에 보이는 큰 갭은 새 하한이
만든 현상이 아니라 원래 전략에도 포함된 꼬리 구간이다.

기여가 크게 사라진다. 따라서 현 시점에서는 관찰 로그를 더 쌓는 편이 임계값을
즉시 좁히는 것보다 타당하다.

## 비교기 결함 수정

7월 19일 해외 연구 보고서는 DB 최신일이 2026-07-16일 때 생성됐지만, 이후
같은 경로의 DB가 2026-07-23까지 갱신됐다. 기존 비교기는 연구 스크립트와
매니페스트 지문만 비교해 이 차이를 놓쳤다.

`scripts/compare_foreign_research_runs.py`는 이제 각 보고서가 기록한 DB 전체
SHA-256, 파일 크기, 최신일을 현재 파일과 비교한다. 스냅샷이 달라지면 성공
보고서를 만들지 않고 명시적으로 실패한다. 따라서 과거 95개 방법 보고서는
당시 스냅샷의 보관 결과이며, 현재 DB 재검증 결과로 오인하지 않는다.

## 해석 한계

- 일봉 시가는 09:01 실제 주문 체결가, 대기열 순서, VI 상태를 재현하지 못한다.
- 일봉 하나에서 손절과 익절이 모두 닿으면 손절 우선으로 처리한 보수적 대리값이다.
- 2024년 이후 자료는 이전 연구에서도 사용해 독립 홀드아웃이 아니다.
- 상장폐지 보강 DB는 생존편향 스트레스이며 완전한 point-in-time 우주는 아니다.
- 소표본 구간의 높은 PF는 재현 가능한 기대수익으로 단정할 수 없다.
- 이번 실행은 계좌·주문 API를 호출하지 않았다.
