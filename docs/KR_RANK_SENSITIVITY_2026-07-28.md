# 국내 갭 후보 랭킹 재검증

2026-07-28 기준으로 현재 전략의 진입 필터와 `-2.25%` 손절, `+12%` 익절, 1만원 자본, 하루 한 종목 규칙을 고정하고 후보를 고르는 랭킹만 비교하는 무주문 백테스트를 추가했다.

## 실험 범위

- 현재 실전 기준: `lowest_price`
- 비교 랭킹: `highest_liquidity`, `most_negative_gap`, `mildest_gap`, `quiet_volume`, `gap_over_range`, `prior_strength`
- 비용: 왕복 `1.35%` harsh, 왕복 `2.45%` extreme
- 구간: `2011~2018`, `2019~2023`, `2024-01-01~2025-03-03`, `2025-03-04 이후`, `2026`
- 강건성: post-NXT 구간에서 가장 큰 수익 거래 25%를 제외해도 손익이 양수인지 확인

실행 결과는 199,606개 이벤트와 3,800개 시장일을 사용했다. 원천 DB 최신일은
2026-07-28이다. 상세 JSON/Markdown은 `data/kr_rank_sensitivity/`에 남기지만
`data/` 결과 파일과 원천 DB는 커밋하지 않는다.

| 랭킹 | harsh 전체 손익 | harsh PF | harsh MDD | harsh post-NXT | extreme post-NXT | post-NXT 상위 25% 제거 | 변경일 | 판정 |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| `lowest_price` 현재 기준 | 104,219원 | 3.81 | 12.1% | 16,146원 | 10,683원 | 7,756원 | 0일 | 유지 |
| `highest_liquidity` | 43,500원 | 1.87 | 28.0% | 629원 | -4,053원 | -4,170원 | 245일 | 제외 |

`most_negative_gap`의 전체 누적손익만 보고 바꾸면 안 된다. 현재 기준보다
post-NXT 손익이 낮고 MDD가 28.4%로 커진다. 또한 모든 대체 랭킹이 현재
기준의 post-NXT 성과와 MDD를 동시에 만족하지 못했으므로 실전 랭킹은
`lowest_price`를 유지한다.

## 승격 기준

비교 랭킹은 다음 조건을 모두 만족해야 실전 후보로 간주한다.

1. 두 비용 가정에서 모든 고정 구간의 손익이 양수다.
2. post-NXT 손익이 현재 `lowest_price` 이상이다.
3. post-NXT MDD가 현재 기준보다 높지 않다.
4. post-NXT 최대 수익 거래 25%를 제거해도 손익이 양수다.

이번 실험은 랭킹을 자동으로 실전 코드에 반영하지 않는다. 일봉 OHLC만으로는 09:01 개장 경매 체결순서, VI, 호가 깊이, 지정가 미체결을 재현할 수 없기 때문이다.

## 실행

```bash
PYTHONPATH=src:scripts .venv/bin/python scripts/kr_rank_sensitivity.py \
  --db-path data/edge_research_universe_15y.sqlite3 \
  --start 2011-01-01 --end 2026-07-28
```
